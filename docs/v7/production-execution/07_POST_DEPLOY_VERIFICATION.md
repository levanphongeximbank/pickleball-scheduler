# Post Deploy Verification

This verification set is a canonical checklist for a later Owner-authorized deployment.

It must cover:
- deployed SHA
- migration and catalog state
- schemas, tables, functions, and RPCs
- RLS/RBAC
- Tenant A/B isolation
- anon/PUBLIC exposure
- authentication
- Owner/Super Admin access
- Club
- Court
- Tournament
- Rating
- Private Pairing Rules
- public portal
- Storage
- Supabase Advisor
- runtime logs
- Vercel deployment health
- PWA assets
- domain aliases
- console critical errors
- monitoring window
